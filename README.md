# DM Configurator
Damiao モーターの設定・書き込みをGUIで行うためのツールです。
SocketCAN / SLCAN どちらもサポートしています。

## 使い方

### SocketCAN を使用する場合
```bash
sudo ip link set can0 up type can bitrate 1000000
sudo ip link set can0 up
```
*設定は環境に合わせて変更してください。

### 起動
```bash
python dm_configurator.py
```
###　接続・設定
接続の設定を行い、接続ボタンを押してください。
接続が成功すると、接続状態が緑に変わります。
> [!note]
> USB-CAN デバイスとの接続完了後、モーターのIDを読み出しています。モーターのIDが正しく設定されていない場合、接続に失敗することがあります。
> モーターのIDを確認し、必要に応じて修正してください。

1. 接続後、モーターから現在の設定を読み出すことを推奨します。ソフト内に各モーターのデフォルト設定はありません。
2. 設定を変更したい項目を編集してください。値を編集してEnterをおすとモーターに送信されます。
3. 「すべて書き込み」ボタンを押すと、現在の設定のすべての項目がモーターに書き込まれます。
4. 書き込み後、モーターから設定を読み出して、変更が反映されていることを確認してください。
5. 設定をCSVに保存・読み込みも可能です。設定を保存するには「設定を保存」ボタンを押し、ファイル名を指定してください。保存した設定は「設定を読み込み」ボタンから読み込むことができます。
6. 設定の変更をモーター内に保存するには、「flashメモリに保存」ボタンを押してください。これにより、モーターの電源を切っても設定が保持されます。

## 注意事項
- モーターのIDなど、すべての値はデータシートに記載されている範囲内で設定してください。
- 設定を変更する前に、現在の設定を読み出してバックアップすることを推奨します。これにより、誤った設定を適用してしまった場合でも、元の設定に戻すことができます。
- 設定の変更は慎重に行ってください。特に、モーターの動作に関わる設定を変更する場合は、モーターが予期せぬ動作をする可能性があるため、十分に注意してください。
- フラッシュメモリに保存する前に、設定が正しいことを確認してください。IDなどで誤った設定をフラッシュメモリに保存してしまうと、接続できなくなるなど可能性があります。
- フラッシュメモリへの保存を不必要に連続して行うことは避けてください。フラッシュメモリには書き込み回数の制限があります。（一般的には数万回程度）
